### Tiledom: On-Chain Mechanics on Solana

Tiledom is an experimental Web3 project that explores decentralised application architecture, on-chain game mechanics, and tokenomics on the Solana blockchain.

### Technical Foundation

#### Rust & Solana
- **Anchor framework** — smart contracts written in Rust using the Anchor framework for Solana.
- **On-chain state management** — efficient account model design for low-latency, low-cost transactions.
- **Solana Pay integration** — native payment flows using SPL tokens.

#### Decentralised Architecture
- **No single point of failure** — fully on-chain logic with no central server dependencies.
- **Open source** — contract code auditable and verifiable on-chain.

#### Why Solana?
Solana's throughput (65,000+ TPS) and sub-cent transaction costs make it the right chain for applications that need real-time interaction — not batch settlement.
